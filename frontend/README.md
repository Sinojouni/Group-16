
## بيانات الدخول (Credentials)

### 🔐 بيانات الإدارة (Admin)
```
البريد الإلكتروني: admin@movierate.com
اسم المستخدم: admin
كلمة المرور: admin123
```

### 👤 بيانات المستخدم العادي (User)
```
البريد الإلكتروني: user@example.com
اسم المستخدم: moviefan2024
كلمة المرور: user123
```
## نظام المصادقة

يستخدم التطبيق نظام مصادقة وهمي (Mock Authentication) للاختبار والتطوير:

- **المصادقة الوهمية**: لا يتطلب خادم خلفي حقيقي
- **البيانات المحفوظة محلياً**: تستخدم localStorage لحفظ بيانات المستخدم
- **رموز الوصول الوهمية**: يتم إنشاء رموز وهمية للجلسات
