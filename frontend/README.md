# 🎬 MovieRate - AI-Powered Movie Recommendation System

## 📋 نظرة عامة (Overview)

MovieRate هو نظام توصية أفلام ذكي مدعوم بالذكاء الاصطناعي، تم تطويره كجزء من مشروع التخرج لبرنامج Samsung Innovation Campus AI Course. يوفر النظام تجربة مستخدم متقدمة لتقييم الأفلام والحصول على توصيات شخصية.

## ✨ المميزات الرئيسية (Key Features)

### 🎯 للمستخدمين
- **تسجيل الدخول وإنشاء الحسابات** مع نظام مصادقة آمن
- **تصفح الأفلام** مع فلاتر متقدمة (النوع، السنة، التقييم)
- **نظام التقييم** من 1 إلى 5 نجوم للأفلام
- **التوصيات الذكية** المخصصة لكل مستخدم
- **قائمة المشاهدة** لحفظ الأفلام المفضلة
- **البحث المتقدم** مع نتائج فورية
- **المراجعات والتعليقات** من المستخدمين الآخرين
- **لوحة تحكم شخصية** لإدارة الملف الشخصي

### 🔧 للإدارة
- **لوحة تحكم إدارية** شاملة
- **إدارة المستخدمين** والأفلام
- **إحصائيات مفصلة** عن النظام
- **إدارة المراجعات** والتقييمات
- **تقارير الأداء** والاستخدام

## 🚀 التثبيت والتشغيل (Installation & Setup)

### المتطلبات الأساسية (Prerequisites)
- **Node.js** 18.0 أو أحدث
- **npm** 9.0 أو أحدث
- **Git** لإدارة النسخ

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   git clone <repository-url>
   cd Group-16-2/frontend
   ```

2. **تثبيت التبعيات**
   ```bash
   npm install
   ```

3. **إعداد متغيرات البيئة**
   ```bash
   # إنشاء ملف .env.local
   echo "VITE_API_BASE_URL=http://localhost:8000/api" > .env.local
   ```

4. **تشغيل الخادم المحلي**
   ```bash
   npm run dev
   ```

5. **فتح التطبيق**
   - افتح المتصفح على: `http://localhost:5173`

## 🔌 تكامل API (API Integration)

### خدمات API
```typescript
// خدمات الأفلام
- getMovies(filters?)           // جلب قائمة الأفلام
- getMovieById(id)             // جلب فيلم محدد
- searchMovies(query)          // البحث في الأفلام
- getMoviesByGenre(genre)      // الأفلام حسب النوع

// خدمات التقييمات
- createRating(movieId, rating) // إضافة تقييم
- getUserRatings(userId)       // تقييمات المستخدم
- getMovieRatings(movieId)     // تقييمات الفيلم

// خدمات المصادقة
- login(credentials)           // تسجيل الدخول
- register(userData)           // إنشاء حساب
- validateToken(token)         // التحقق من الرمز
```

### تكامل الخادم الخلفي
- **Django REST Framework** للـ API
- **JWT Authentication** للمصادقة
- **CORS** للطلبات عبر النطاقات
- **Error Handling** شامل للأخطاء
